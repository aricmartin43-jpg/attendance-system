Help with location access
  1. Open this portal directly in Chrome or Safari. If you opened a link inside WhatsApp or another app, use its menu to open the link in your browser.
  2. Turn on Location Services in your phone settings. Allow your browser to use location while you are using it, with precise location enabled where available.
  3. In the browser’s settings for this website, set Location to Allow. Reload the page after changing permission.
  4. Keep Wi-Fi or mobile data on. If the signal is weak inside the factory, try near a window or outdoors. Set the phone date and time to automatic.

Use “Check location” to test permission and signal. This does not record a check-in or check-out. If it still fails, send the displayed error to your administrator.
